# Experimental Results & Model Metrics

This directory stores evaluation metrics, classification reports, and benchmarking outputs for the SovereigntyAI advisory machine learning models.

## Current Artifacts
- **`model_metrics.json`:** Comprehensive evaluation dictionary generated by `scripts/train_ml_model.py`.
  - **Model:** `RandomForestClassifier` (scikit-learn)
  - **Dataset:** Synthetic Cloud Compliance Dataset (1,200 samples)
  - **Test Samples:** 240 (Holdout test split)
  - **Accuracy:** 96.25%
  - **Macro Avg F1:** 0.9602
  - **Weighted Avg F1:** 0.9623

To inspect results in terminal:
```bash
python3 scripts/evaluate_model.py
```
Detailed performance breakdowns and confusion matrices are documented in `docs/Testing_Report.md`.
